🚗 SwiftDrive – Vehicle Rental Management Website

Web Application | HTML | CSS | JavaScript | PHP | MySQL

📌 Project Overview

SwiftDrive is a web-based vehicle rental management system developed to make vehicle rental services more accessible, convenient, and efficient for users.

The website provides a user-friendly platform where customers can explore available vehicles, view vehicle details, make rental bookings, and manage their rental information.

This project was developed as part of my Computing and Software Engineering studies at ICBT Campus, Sri Lanka.

🎯 Project Objectives

* Develop a user-friendly vehicle rental website.
* Allow customers to explore available vehicles.
* Make vehicle booking easier and more convenient.
* Provide an efficient vehicle rental management system.
* Store and manage customer and booking information.
* Improve the overall vehicle rental experience.

⚙️ Installation Guide

1. Clone this repository.

git clone https://github.com/ragavan-janoyan/swiftdrive.git

2. Install and open XAMPP.
3. Start Apache and MySQL.
4. Copy the SwiftDrive project folder into the htdocs directory.
5. Open phpMyAdmin.
6. Create a new database and import the provided SQL file.
7. Configure the database connection in the project.
8. Open your browser and visit:

http://localhost/SwiftDrive/

🗄️ Database

SwiftDrive uses MySQL to store and manage application data, including customer details, vehicle information, and rental booking records.

Database configuration and setup instructions are included in the project.
